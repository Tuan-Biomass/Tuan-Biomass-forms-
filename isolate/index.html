Planned maintenance or upgrade
e.g. scheduled downtime		 Yes Lockout Officer Lockout Officer must coordinate and verify all isolations before work commences.
Emergency breakdown Yes Isolation Trained Worker Only if Lockout Officer not immediately available. Worker must follow the site isolation checklist.
Routine low-risk maintenance
e.g. sensor cleaning, basic blockage		 Yes Isolation Trained Worker Lockout using personal lock and tag. Confirm zero energy state before task start.
Contractor work on site Yes Lockout Officer Lockout Officer must coordinate and verify all isolations. Contractor must hold a personal lock.
Multiple isolation points involved Yes Lockout Officer Complex lockouts must be centrally managed. Use group lockout hasp where required.
Single person, simple isolation Yes Isolation Trained Worker Must apply personal lock and tag with name and contact details. Verify isolation before proceeding.
Training or onboarding involving equipment Yes Lockout Officer Always supervised. Lockout Officer must be present throughout for safety and instruction.
